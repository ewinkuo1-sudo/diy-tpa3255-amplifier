# TPA3255 DIY 立體聲後級

使用 TI TPA3255 自畫電路與 PCB，搭配材料選用、3D 機構與量測，完成一台練習機／備用後級，記錄 AI 協作過程供課堂展示。

## 目前進度

V0.1 架構與計算階段：暫定外接 48V DC、雙聲道 BTL，以 2×50W / 8Ω 為第一階段設計目標。這不是已實測性能；原理圖、PCB 與加工圖尚未完成。

## 下一步

準備 KiCad 工具，核對完整原廠原理圖，依序完成供電／控制、輸入級、功率級與濾波，再確定實際料號、板形和機構尺寸。
