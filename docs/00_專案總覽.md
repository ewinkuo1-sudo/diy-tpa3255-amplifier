# TPA3255 專案總覽

> 從舊雙軌總覽抽出 TPA3255 部分。以下數字保留為歷史草案，與現行規格不一致時，以 [V0.1 設計規格](V0.1_設計規格.md) 及 [電路設計](01_電路設計.md) 的已查核內容為準。價格與比較未於拆分時重新驗證。

用 TI TPA3255 晶片從零設計整塊 D 類放大板。學完整的 Class D PCB 設計流程。

| 指標 | TPA3255 DIY | vs C 298 |
|---|---|---|
| THD+N | ~0.01%（1W）| 差 10–100 倍 |
| SNR | ~105–110dB | 差 10–15dB |
| 功率 | 315W×2 / 4Ω（BTL，10% THD）；175W×2 / 8Ω | 4Ω 功率更大 |
| 回授 | pre-filter（LC 濾波器之前）| C 298 是 post-filter，頻響不受喇叭阻抗影響；TPA3255 會 |
| 效率 | >90% | 同等級 |

**你要畫的 PCB（2 塊）：**
1. **放大板** — TPA3255 + LC 輸出濾波 + 頂面散熱片 + 保護（這是核心）
2. **電源板** — 依本專案重新設計；V0.1 採外接電源構想

**預估成本：**

| 項目 | 估價（NT$）|
|---|---|
| TPA3255 ×1（雙聲道）| $250–400 |
| LC 濾波電感、薄膜電容、MLCC | $300–500 |
| 散熱片 + 導熱墊（IC 頂面 PowerPAD）| $100–300 |
| PCB 製板（四層）| $200–400 |
| 電源（48V SMPS 或變壓器整流）| $500–1,000 |
| 機殼、端子 | $500–1,000 |
| **合計** | **NT$2,000–3,600** |

**完成後用途**：推電腦桌面喇叭或當備機。
