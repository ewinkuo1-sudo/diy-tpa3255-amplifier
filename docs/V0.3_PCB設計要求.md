# V0.3 PCB 設計要求

依使用者要求，以下由設計端處理，不要求使用者自行決定走線。這是下階段的設計輸入，目前尚無 PCB。

| 區域 | 佈局與驗收要求 |
|---|---|
| 功率級 | 依 TI EVM 與資料表縮短 PVDD／半橋／去耦回路；bootstrap 電容放在對應 BST 與 OUT 腳旁 |
| 地平面 | 維持連續地平面，靠元件分區與回流路徑控制干擾；不任意切割地平面 |
| PFFB | 從各自 LC 濾波後的輸出取樣；回授走線遠離 OUT 開關節點與電感，保持四臂對稱 |
| 輸入 | RCA、XLR 接收器與 NE5532 放在低噪聲區；12V 類比去耦在元件旁；避免主電流流過輸入地與 VMID 回路 |
| XLR | 母座 pin 1／金屬外殼在入口接 CHASSIS；R608 單點接訊號 GND，RCA 插座絕緣；pin 2／3 走線及 47Ω／47µF 支路對稱；四顆輸入電容按聲道配對到 1% |
| 輸入選擇 | J603／J604 保留短路帽及操作空間，標清 RCA 1–2／XLR 2–3，初裝 XLR；前端配線短，面板切換與靜音另行設計 |
| 接收器參考 | U602 到 U601 REF 走線短；不與功率電流共用回流；INA2137 不能直接以未緩衝的 VMID 分壓器驅動 REF |
| 電感 | 四顆 MA5172-AE 各預留 28.6×12.3mm 本體包絡；腳距 10±0.5mm、最大線徑 1.07mm；鑽孔及焊盤另行核定，重件需固定 |
| 開關電源路徑 | TPS26631 的 PowerPAD 接地與導熱過孔，STPS5H100B 的 cathode tab 電位不可誤接 GND；依損耗分配銅面，遠離前端 |
| 控制 | U302–U307 各有本地去耦；CT、SENSE 與保持電容遠離開關節點；eFuse 設定電阻靠近 IC |
| Trigger | 絕緣插座；TRIG_RETURN 不接 GND／機殼；隔離兩側的銅面與焊盤不可誤連 |
| 喇叭端 | BTL 兩端均為輸出；左右負端不共接、不接機殼；預留差動量測位置 |
| 機構 | 為兩個 XLR 母座、兩個 RCA、絕緣 Trigger 插座與電源／喇叭端子預留後板空間；高度與散熱器仍需實際封裝核對，V0.1 機殼只是占位；八頁原理圖不表示八塊 PCB |

來源：[TPA3255 §12](https://www.ti.com/lit/ds/symlink/tpa3255.pdf)、[TPA3255EVM](https://www.ti.com/lit/ug/slou441/slou441.pdf)、[PFFB §1–2](https://www.ti.com/lit/an/slaa788a/slaa788a.pdf)、[TPS2663 §10](https://www.ti.com/lit/ds/symlink/tps2663.pdf)、[Coilcraft 外形圖](https://www.coilcraft.com/getmedia/5fb1a3ea-b3b6-4ae7-89c3-2a4c68c350e4/ma5172.pdf)。

XLR 接收器腳位、Sense／REF 與去耦依 [INA2137 原廠資料](https://www.ti.com/lit/ds/symlink/ina137.pdf) 核對；母座封裝需再依選定製造商確認，不能以通用三腳符號猜測實際孔位。

板層、線寬、孔徑、銅厚及距離必須依製程、溫升與回路要求核定；這張表不替代 DRC、熱分析或實機量測。
