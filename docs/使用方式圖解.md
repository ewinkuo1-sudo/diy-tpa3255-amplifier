# 先看這台後級怎麼用

原理圖是在說明每個零件怎麼接。要理解這台產品，可以先從自己的設備和操作看起。

[放大看圖](preview/amplifier-explained.svg)

## 你每天會接觸的部分

**Z10 送出音樂 → 這台後級提供推動喇叭的力量 → 左右喇叭發聲。** 音量由 Z10 控制。

| 接什麼 | 做什麼 |
|---|---|
| 音樂線 | 從 Z10 接到後級。規劃使用左右兩條 XLR，也保留 RCA 輸入。第一版由機內跳線選擇，尚未設計面板輸入切換開關。 |
| 喇叭線 | 從後級接到左右喇叭，左右各一組。 |
| 一條市電電源線 | 從牆壁插座接到後級機背；主電源與待機電源都放在機箱裡。 |
| Trigger 控制線 | 前級透過這條線通知後級開機或待機。它不傳音樂，也不供應後級用電；不接這條線仍可手動開機。 |

前方規劃 **AUTO／OFF／ON**：AUTO 跟隨前級的 Trigger，OFF 進入待機，ON 手動開機。這些操作都以後方總電源開關已開啟為前提；音量交給 Z10。

待機會先靜音，再停止功率級供電；機內電源與控制電路仍有電、仍耗電。後方總電源開關關閉後，前級就不能喚醒後級。

## 原理圖和成品的關係

機箱內規劃主電源、待機電源、擴大電路與開關控制。原理圖把它們細分成零件與接線，供設計、檢查及製作電路板使用；圖上的位置不代表零件在機箱裡的實際位置，八頁圖也不代表八塊板。

這張圖是使用方式與功能示意，**不是定案外觀或實際內部配置**。目前已開始[PCB 零件配置](../electrical/pcb-draft/README.md)，尚未走線或製成實機；電源保護、散熱、機構與 Z10 Trigger 相容性仍需完成設計或驗證。

需要了解內部供電時，再看[電源架構](../electrical/system-power/README.md)；零件與接線細節見[八頁原理圖](../electrical/v03/README.md)。
