## 核心概念

用 TI TPA3255 晶片從零設計 D 類放大板。完整的 PCB 設計練習，完成後當備機或推桌面喇叭。

## TPA3255 規格（datasheet）

- 類型：Class D，閉迴路模擬回授，**pre-filter feedback**（回授取自 LC 濾波器之前的切換輸出）
- 輸出模式：4ch SE / 2ch BTL（立體聲）/ 1ch PBTL（單聲道橋接）/ 2.1 混用
- 功率：
  - 2ch BTL：315W×2 / 4Ω、185W×2 / 8Ω（10% THD+N）；1% THD+N 為 260W×2 / 4Ω、150W×2 / 8Ω（原廠條件，非本案實測）
  - 1ch PBTL：600W / 2Ω
- THD+N：~0.01%（1W，1kHz）
- SNR：~105–110dB（A-weighted）
- 效率：>90%
- 電源：PVDD 功率電源：4Ω 條件建議 18–53.5VDC（§7.3）；另需 VDD / GVDD 輔助供電
- 增益：晶片沒有 GAIN0 / GAIN1；§7.5 列典型 21.5dB。整機增益需連同前端與差動訊號定義計算
- 封裝：HTSSOP-44（DDV），**PowerPAD 在封裝頂面**，腳距 0.5mm
- 內建保護：過流、過溫、欠壓、短路、DC 偵測

## Pre-filter feedback 的意義

TPA3255 的回授迴路不包含輸出 LC 濾波器，所以：

- LC 濾波器的頻率響應直接呈現在喇叭端，**會隨喇叭阻抗變化**（4Ω 與 8Ω 的高頻響應不同）
- 電感的線性度、DCR、飽和特性直接影響失真與阻尼
- 這是它與 Purifi / Hypex（post-filter feedback）在架構上的根本差異，也是性能差距的主要來源
- 設計上的結論：**LC 濾波器要照 datasheet 的表選值，並針對目標喇叭阻抗選**，電感要用夠好的

## 散熱：PowerPAD 在頂面

DDV 封裝的散熱墊在**晶片上方**，不是像多數 QFN 那樣在底部。

- 散熱片要壓在 IC 頂面，中間夾導熱墊，用螺絲固定到 PCB 上 → **PCB 上要預留散熱片固定孔**，layout 時要把 IC 周圍的高元件清開
- 300W 級持續輸出會需要不小的散熱片（TPA3255EVM 附的散熱片可當尺寸參考）
- 反過來說，因為底部沒有需要回焊的大散熱墊，這顆其實**可以手焊**（0.5mm 腳距拖焊，要經驗與好的助焊劑）

## 焊接選項

1. **SMT 組裝服務** — 依實際 BOM、封裝庫存、數量與工程費取得報價
2. **手焊拖焊** — 可行（見上節），但 0.5mm 腳距沒經驗容易橋接
3. **TPA3255EVM** — TI 官方評估板可作參考與量測對照；價格待查，自畫設計仍可保留學習價值

建議：PCB 自己畫，SMT 交給 JLCPCB 貼；有預算的話另外買一片 EVM 當對照組。

## 電路架構

```
RCA 輸入 ──→ [輸入耦合與濾波] ──→ [TPA3255] ──→ [LC 輸出濾波 + Zobel] ──→ 喇叭
                                      ↑   ↑
                                   PVDD  頂面散熱片
                                （36–53V）
```

### 1. 輸入級
- 差動輸入，輸入耦合電容隔 DC（值依 datasheet；§7.5 列輸入電阻典型 20kΩ，前端仍須依實際差動接法分析）
- 輸入衰減與前端增益須依訊源最大電平、晶片差動輸入與削波餘裕計算
- 單端 RCA 進來可接 datasheet 的單端接法，或前面加一級單端轉差動

### 2. 輸出 LC 濾波
- Class D 最關鍵的部分，功能是把 PWM 方波濾成音頻
- TPA3255EVM 4Ω 參考值：**L = 10µH、C = 1µF 薄膜**；8Ω 負載照 datasheet 濾波器表調整
- 電感依負載峰值加開關紋波、偏磁後電感量、DCR 與溫升選型；不能以價格或單一電流數字判定
- 輸出加 **Zobel / snubber RC**（datasheet 有值），抑制高頻振鈴
- **Layout 最敏感區域**：IC 輸出到 LC 的走線要短，迴路面積小

### 3. Bootstrap 與去耦
- 每個半橋一顆 **bootstrap 電容 33nF**（0603 / 0805 陶瓷，耐壓 ≥100V）。**不要加大**，datasheet 明講加大會增加峰值電流、有可靠度風險
- PVDD 去耦：每對 PVDD 腳 **1µF / 100V 陶瓷**貼在腳旁；板上大電容依電源阻抗、負載瞬變、紋波與額定電壓選定；取消未經計算的固定容量下限
- DVDD / GVDD 去耦：依 datasheet（10µF + 0.1µF 等級）
- 外部 12V：供 VDD 與 GVDD_AB/CD。**DVDD / AVDD 是內部穩壓器輸出，只接規定去耦，不可接 12V 或拿來供外部電路**（§11.1）

### 4. 保護與控制腳位
- RESET、FAULT、CLIP_OTW 腳位拉到 LED 或 MCU，方便除錯
- 開機順序依 datasheet（§11.2–11.3，需同時處理主／輔助電源與 RESET，不以單一延遲代替時序驗證）

## PCB Layout 關鍵注意事項

Class D 的 layout 比 Class AB **敏感得多**：

1. **建議直接用四層板** — JLCPCB 四層只多幾百元，可拿完整地平面與電源平面，雙層板很難同時顧到迴路面積與地完整
2. **PWM 輸出到 LC 濾波器的走線要短** — 幾百 kHz 的大電流方波，走線就是天線
3. **PVDD 去耦電容直接貼在 IC 腳旁** — 回流路徑越短越好
4. **依原廠佈局管理回流** — 用元件分區控制大電流路徑；不能把「單點接地」當任意切割地平面的規則
5. **輸入訊號遠離 PWM 輸出與電感** — 高頻串擾
6. **散熱片固定孔與淨空** — 頂面散熱片要壓得上去，IC 周圍留空
