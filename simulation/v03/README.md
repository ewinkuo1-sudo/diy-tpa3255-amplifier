# V0.3 模型與結果

執行 `python3 tools/verify_v03.py`，從 V0.3 實際 KiCad netlist 建立 AC 模型並核對控制腳位。

- `ac-rca-*`／`ac-xlr-*` 的 `.cir`／`.csv`：兩種輸入各有 4Ω、8Ω、空載近似，以及理想功率級或自訂 100kHz 極點兩種假設，共十二組。XLR 以 pin 2／3 各 ±0.5V 形成 1V 差動，RCA 使用 1V。運放只有理想有限增益，沒有真實頻寬、噪聲及失真。空載使用 1GΩ 數值近似。
- `ac-summary.csv`：20Hz／1kHz／20kHz 的增益與相對 1kHz 響應，包含輸入種類。
- `ac-common-*`／`xlr-external-imbalance.csv`：同相驅動 XLR 正負腳；一組理想匹配，一組外部 47Ω 電阻 ±0.1%、配對 47µF 電容 ±0.5%。INA2137 內部四電阻採名義 12kΩ／6kΩ 理想比例；理想匹配案例的極大抑制數值只是數值運算殘差，不是實機性能。外部公差案例也未包含晶片內部失配、真實 REF 阻抗、電容漏電／ESR 與訊源阻抗。
- `sequence-*.csv`：控制時序規格模型，由腳位審查後的阻容值與電源門檻驅動。涵蓋正常開關、缺少任一電源、5ms Trigger 脈衝、主／輔助電源掉壓與 eFuse 故障鎖定。不是實際半導體暫態模擬。

改為機內雙電源後，另加 `sequence-psu_48v_late.csv` 與 `sequence-psu_12v_late.csv`，驗證兩個電源啟動順序互換時，均等待供電良好及延遲後才開聲。1s／3s 階躍是測試刺激，不是廠商實際啟動波形；完整控制案例共九個。尚未模擬市電側、電源實際突波或 3.3V 控制電源崩落的半導體行為。

輸入選擇端在 KiCad 是三腳接頭，模型明確閉合所選模式的接點；XLR 正負腳、耦合、Sense、REF 與參考緩衝器使用實際 netlist。電源偏壓仍理想化，沒有模擬上電偏壓建立、切換爆音或功率放大器 clipping。

完整數值與限制見 [驗證報告](../../electrical/v03/validation.md)。所有數據為設計模型輸出，沒有實測資料。
